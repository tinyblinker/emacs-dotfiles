* Overview

A lightweight GNU Emacs 31.1 configuration focused on *Rust*
(eglot + rust-analyzer + tree-sitter) and *Org-mode* notes.  It also
borrows several ideas from Neovim (telescope-style search, flash-style
jumps, surround-style editing).

The configuration is modular: each plugin lives in its own file under
=~/.config/emacs/modules/=.  =init.el= loads them in order;
=early-init.el= sets up package mirrors, quickstart, and GC tuning.

* Requirements

Run =./install-dependencies.sh= to install the system packages, or
install them manually.

| Package          | Used by                                   |
|------------------+-------------------------------------------|
| =ripgrep=        | consult-ripgrep (live grep)               |
| =fd=             | dirvish (fast file search)                |
| =chafa=          | dirvish (image preview)                   |
| =poppler=        | dirvish (PDF preview)                     |
| =graphviz=       | org-roam (graph layout, =fdp=)            |
| =cmake= =libvterm= | vterm (terminal module)                 |
| =ffmpegthumbnailer= | dirvish (video thumbnails, optional)    |
| =texlive-core=   | org-mode LaTeX preview (dvisvgm, optional) |

Non-pacman dependencies:

- =rust-analyzer= :: =rustup component add rust-analyzer=
- =mmdc= (mermaid-cli) :: =npm install -g @mermaid-js/mermaid-cli= (for ob-mermaid)
- Rust tree-sitter grammar :: compiled and placed in =~/.config/emacs/tree-sitter/=

ELPA packages are installed automatically on first launch via
=use-package :ensure t=.

* Install

#+begin_src bash
  git clone <this-repo> ~/.config/emacs
  cd ~/.config/emacs
  ./install-dependencies.sh
#+end_src

Launch Emacs.  Packages install automatically on the first run.

* Keybindings

** Navigation
| Key     | Action                                   |
|---------+------------------------------------------|
| =C-o=     | jump backward (better-jumper)            |
| =C-M-o=   | jump forward (better-jumper)             |
| =M-g c=   | jump to a character (avy)                |
| =M-g l=   | jump to a line (avy)                     |

*Note:* =C-i= is the same as =TAB= in Emacs, so forward jump uses =C-M-o=.

** Search (consult)
| Key     | Action                                          |
|---------+-------------------------------------------------|
| =C-x b=   | fuzzy switch buffer/file                       |
| =M-s l=   | fuzzy search in current buffer (consult-line)  |
| =M-s g=   | live grep in project (consult-ripgrep)         |
| =M-s r=   | restore search history (consult-history)       |
| =M-g g=   | go to line (consult-goto-line)                 |
| =M-g i=   | outline/imenu navigation (consult-imenu)       |
| =M-y=     | fuzzy yank (consult-yank-pop)                  |

** Embark

|------+---------------------------------|

* Notes

- *Rust mode:* =.rs= files open in the tree-sitter =rust-ts-mode=.  The
  =rust-mode= package is kept only for the cargo commands.
- *Fonts:* the icons need a Nerd Font (JetBrainsMono NF is used).  If
  icons look broken, run =M-x nerd-icons-install-fonts=.
- *Tree-sitter:* grammars go in =~/.config/emacs/tree-sitter/= and are
  found automatically through =treesit-extra-load-path=.
