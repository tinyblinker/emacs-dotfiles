* Implementing a Trait on a Type
给NewsArticles和SocialPost结构体数据类型实现Summary traits
在后文中调用这个Summary traits以使用各自不同的实现
#+begin_src rust
  pub struct NewsArticle {
      pub headline: String,
      pub location: String,
      pub author: String,
      pub content: String,
  }

  impl Summary for NewsArticle {
      fn summarize(&self) -> String {
          format!("{}, by {} ({})", self.headline, self.author, self.location)
      }
  }

  pub struct SocialPost {
      pub username: String,
      pub content: String,
      pub reply: bool,
      pub repost: bool,
  }

  impl Summary for SocialPost {
      fn summarize(&self) -> String {
          format!("{}: {}", self.username, self.content)
      }
  }

  fn main() {
      let post = SocialPost {
          username: String::from("horse_ebooks"),
          content: String::from(
              "of course, as you probably already know, people",
          ),
          reply: false,
          repost: false,
      };
        
      println!("1 new post: {}", post.summarize());
  }
#+end_src
* Using Default Implementations
为NewsArticles使用Summary的默认实现,即调用summarize时输出"(Read more...)"
#+begin_src rust
  pub trait Summary {
      fn summarize(&self) -> String {
          String::from("(Read more...)")
      }
  }
  impl Summary for NewsArticle {}
#+end_src
traits内部可以调用内部的函数,而此时实现traits只用实现最基本的那个方法就行了
,因为其他的methods可以由最基本的methods自举出来
#+begin_src rust
  pub trait Summary {
      fn summarize_author(&self) -> String;

      fn summarize(&self) -> String {
          format!("(Read more from {}...)", self.summarize_author())
      }
  }
  impl Summary for SocialPost {
    fn summarize_author(&self) -> String {
        format!("@{}", self.username)
    }
  }
  #+end_src
* Using Traits as Parameters
作为函数形参:两个函数等价,上面的是Syntax Sugar;
本质行为是限制实现了特定traits的dataType才能被接受
#+begin_src rust
  pub fn notify(item: &impl Summary)
      println!("Breaking news! {}", item.summarize());
  }
  pub fn notify<T: Summary>(item: &T) {
      println!("Breaking news! {}", item.summarize());
  }
#+end_src
更多例子:("+"的使用,"where"的使用)
#+begin_src rust
  // 多个函数形参限制使用不同的traits
  pub fn notify(item1: &impl Summary, item2: &impl Summary) {
      unimplemented!();
  }
  pub fn notify<T: Summary>(item1: &T, item2: &T) {
      unimplemented!();
  }
  // 某个函数形参限制实现多个traits(用"+")
  pub fn notify(item: &(impl Summary + Display)) {
      unimplemented!();
  }
  pub fn notify<T: Summary + Display>(item: &T) {
      unimplemented!();
  }
  // 用where配合GenericTypes简化函数签名,更好看地restrict traits
  fn some_function<T: Display + Clone, U: Clone + Debug>(t: &T, u: &U) -> i32 {
      unimplemented!();
  }
  fn some_function<T, U>(t: &T, u: &U) -> i32
  where
      T: Display + Clone,
      U: Clone + Debug,
  {
      implemented!();
  }

* Using Trait Bounds to Conditionally Implement Methods
如果Pait中的T实现了Display和PartialOrd,那么就比较(PartialOrd Traits)
,并打印(Display Traits)较大值
#+begin_src rust
  use std::fmt::Display;

  struct Pair<T> {
      x: T,
      y: T,
  }

  impl<T> Pair<T> {
      fn new(x: T, y: T) -> Self {
          Self { x, y }
      }
  }

  impl<T: Display + PartialOrd> Pair<T> {
      fn cmp_display(&self) {
          if self.x >= self.y {
              println!("The largest member is x = {}", self.x);
          } else {
              println!("The largest member is y = {}", self.y);
          }
      }
  }
#+end_src
